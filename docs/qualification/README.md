# Qualification schemas and templates

These schemas, corpus definitions, and evidence templates are inputs to existing qualification and regression checks. Preserve their filenames, schema identities, and declared release targets when changing ordinary documentation.

The benchmark schemas describe frozen generalization cases. The gold-corpus manifest and templates support the retained product-qualification protocol. A blank template or valid schema is not a completed review or a current performance result.

See [Testing](../TESTING.md) for current commands and the [qualification reference](PROTOCOL.md) for the earlier protocol.
